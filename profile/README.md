Independent software for backing up and protecting data, mostly written in Rust.
See [fivelayer.dev](https://fivelayer.dev) for what we're working on.

| Project | What it does | Status |
|---|---|---|
| [vss-snapshot](https://github.com/fivelayer-dev/vss-snapshot) | Temporary, read-only Windows Volume Shadow Copy snapshots from Rust, including files that are open or locked | In development |
| Encrypted backup | Versioned backups for Windows and Linux, stored locally or in the cloud | In development, not public yet |
