# Five Layer

Independent software for backing up and protecting data, mostly written in Rust.

**Website:** [fivelayer.dev](https://fivelayer.dev)

## Open source

- **[vss-snapshot](https://github.com/fivelayer-dev/vss-snapshot)**: take temporary, read-only
  Windows Volume Shadow Copy snapshots from Rust, including files that are open or locked.
  In development.

## In development

An encrypted, versioned backup system for Windows and Linux, with local and cloud storage.
